# ACO -> NOTALD transfer experiment plan

Date: 2026-08-28
Branch: `aco-notald-transfer`

This plan is written before inspecting any outcome from the new ant-colony implementation.

## Research sequence

The work is intentionally split into two experiments.

### Experiment 1 - ACO implementation sanity check

Purpose: establish only that the ant-colony search mechanism can plausibly solve a known, independently checkable theorem-like problem and that successful paths actually reinforce later search.

Problem: one frozen Ocean implication instance with declared shortest proof length `L*=20`, seed 1, generated by the repository's existing `benchmarks/ocean/generate_ocean_tptp.py` generator. The generator independently checks the shortest source-to-target distance by BFS before writing the TPTP problem.

The ant solver is not given the planted route or the BFS distances. It sees only the start atom, implication axioms, and goal atom.

Search mechanism:

- each ant performs stochastic bounded depth-first proof search with backtracking;
- candidate implication edges are ordered by a pheromone-weighted local rule;
- successful source-to-goal chains deposit pheromone inversely proportional to proof length;
- pheromone evaporates between colony iterations;
- an otherwise identical no-learning control keeps pheromone uniform;
- no target-distance oracle, planted route, or BFS result may be used by the ant policy.

Sanity criteria:

1. the ACO solver must emit at least one source-to-target chain;
2. an independent checker must confirm that every step is an actual problem axiom and that the chain begins at the declared source and ends at the declared target;
3. the generator's independent BFS check must still report `L*=20`;
4. pheromone on at least one verified successful path must be measurably reinforced relative to the global edge background.

ACO-vs-random expansion differences are recorded but are descriptive in Experiment 1. They are not the scientific claim of the sanity check.

### Experiment 2 - learn set.mm, freeze, then test NOTALD/Ocean at high n

Experiment 2 starts only after Experiment 1 passes its implementation sanity criteria.

Training corpus: the complete pinned `set.mm` revision available to the training pipeline. Because the high-n Ocean/NOTALD instances are generated outside `set.mm`, no `set.mm` theorem needs to be withheld merely to prevent target-proof leakage.

The learned object must be frozen before any high-n test outcome is inspected. The transfer layer will be restricted to representation-independent search-control information that can be defined both for Metamath search and Ocean search (for example branching, depth, progress/stagnation, reuse, exploration/exploitation, and colony-control parameters). It must not encode Ocean seed identities, planted paths, BFS distances, or high-n solutions.

Primary high-n test: the repository's existing 20 frozen-style `L*=4000` Ocean instances, seeds 1-20.

Comparison:

- untrained ACO control;
- set.mm-trained/frozen ACO controller;
- same high-n instances and resource budgets.

Primary measurements:

- independently verified settlements;
- expansions;
- edge-selection / search transactions;
- wall time;
- ants and colony iterations to first settlement;
- emitted proof length and gap from the known exact `L*`;
- verifier calls / verification cost where applicable.

A high-n `UNKNOWN` means only unknown under the declared finite controls. No target is called settled without independent verification.

## Interpretation boundary

Experiment 1 is an implementation sanity check and must not be reported as evidence that training on `set.mm` transfers to NOTALD. Experiment 2 is the transfer experiment.
